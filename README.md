# 月明·视频发布

把已确认的视频与封面准备到所选创作者平台，回读关键字段，并在授权后逐个平台提交。

## 你会得到什么

- 小红书、抖音、B 站、视频号的自动草稿准备，以及 YouTube 的 Ego 操作流程
- 上传完成、标题、声明、封面等核验记录
- 可恢复的任务状态与逐平台结果

## 试着这样说

```text
用 moonlit-video-publisher。把这个已经确认的视频包准备到我配置的抖音和 B 站账号，检查封面、标题与原创声明，先让我核对草稿。
```

## 安装与首次使用

将本仓库的完整目录交给支持本地 Skill 的 Agent 安装，保留 `SKILL.md` 与随附资源。已有同名版本时先检查差异；使用版本锁的工作区沿用自身升级机制。

让 Agent 安装：

```text
请安装这个 Skill：https://github.com/zzyong24/moonlit-video-publisher
```

也可通过 Skills CLI 安装：

```bash
npx skills add zzyong24/moonlit-video-publisher
```

## 配置与依赖

需要 Node.js、ego-browser／Ego Lite、可用的平台账号以及已确认的视频发布包。首次使用配置可用平台、默认平台和真实原创策略；用户配置和登录态保存在仓库外。

## 数据与使用边界

准备阶段会向选定平台上传视频、封面和文案。最终发布权限只在当前任务内有效，任务文件不保存授权。当前执行规则存在账号、浏览器和原创建议的适用限制，详见 SKILL.md；不能把脚本运行结束等同于发布成功。

## 详细说明

执行流程与资源导航见 [SKILL.md](SKILL.md)。安装检查不代表真实业务验收；需要外部服务、账号登录或付费生成的步骤，应在使用者自己的环境中验证。

## 2.8.1：视频号微信授权恢复

已有明确授权时，由 Agent 核对官方微信授权弹窗和身份后点击“允许”，不重复交回用户代点。若原生工具误截微信主窗口，先按实时窗口几何取得系统截图，再用当前可见按钮位置操作；登录成功后核对目标视频号昵称与稳定 ID。系统权限拒绝、身份不明或确需本人扫码/MFA时仍报告具体卡点，不绕过系统授权。

此版本更新已实测的操作流程，未声称具备全自动微信登录适配器；不携带个人账号、窗口坐标或登录态。

## 2.9.0：加入 YouTube

支持通过 Ego 的单控制者操作流程发布 YouTube 视频：频道身份核对、独立三审、16:9封面、受众与AI问卷、版权检查、公开范围、一次提交及观看页实播验收。可在私有 `youtube.json` 配置“全平台”时包含 YouTube；账号信息不随 Skill 分发。详见 [YouTube流程与验收边界](references/platform-youtube.md)。

既有CLI仍编排四个平台，YouTube由Agent按已实测流程补充执行；尚未实现无人值守第五适配器、自动跨五平台调度或中断恢复验收。
