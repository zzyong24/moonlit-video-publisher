# 月明·四平台视频发布

把已确认的视频与封面准备到所选创作者平台，回读关键字段，并在授权后逐个平台提交。

## 你会得到什么

- 小红书、抖音、B 站、视频号所选平台的草稿准备
- 上传完成、标题、声明、封面等核验记录
- 可恢复的任务状态与逐平台结果

## 试着这样说

```text
用 moonlit-video-publisher。把这个已经确认的视频包准备到我配置的抖音和 B 站账号，检查封面、标题与原创声明，先让我核对草稿。
```

## 安装与首次使用

将本仓库的完整目录交给支持本地 Skill 的 Agent 安装，保留 `SKILL.md` 与随附资源。已有同名版本时先检查差异；使用版本锁的工作区沿用自身升级机制。

让 Agent 安装：

```text
请安装这个 Skill：https://github.com/zzyong24/moonlit-video-publisher
```

也可通过 Skills CLI 安装：

```bash
npx skills add zzyong24/moonlit-video-publisher
```

## 配置与依赖

需要 Node.js、ego-browser／Ego Lite、可用的平台账号以及已确认的视频发布包。首次使用配置可用平台、默认平台和真实原创策略；用户配置和登录态保存在仓库外。

## 数据与使用边界

准备阶段会向选定平台上传视频、封面和文案。最终发布权限只在当前任务内有效，任务文件不保存授权。当前执行规则存在账号、浏览器和原创建议的适用限制，详见 SKILL.md；不能把脚本运行结束等同于发布成功。

执行流程与资源导航见 [SKILL.md](SKILL.md)。安装检查不代表真实业务验收；需要外部服务、账号登录或付费生成的步骤，应在使用者自己的环境中验证。
